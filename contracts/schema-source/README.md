# Aggregate schema source

`consumer-api-20260813.1.json` is the authoring source from which the immutable
Consumer Core and capability-scoped OpenAPI artifacts are generated. It is not
served as a public contract and has no externally negotiated digest.

Run `python3 tools/generate_capability_schemas.py` after editing it. The checked
in generated artifacts and their digests are the public wire identities.
Run the same command with `--check` in validation so stale generated bytes fail
without mutating the workspace.

Run `python3 tools/validate_contract_artifacts.py` to resolve local references,
validate canonical fixtures with JSON Schema Draft 2020-12, and verify the
immutable digest lock. Its pinned dependency is listed in
`tools/requirements-contract-validation-20260813.txt`.

`contracts/immutable-contract-digests.json` is an append-only release fence.
Once a dated artifact is listed there, the generator refuses to change its
bytes. Evolve a published contract by creating a new dated version and adding
its reviewed digest; never edit or remove an existing lock entry.
